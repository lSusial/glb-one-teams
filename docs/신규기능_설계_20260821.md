## ① 국가별 지표 스트립 (환율·지수)

- **위치**: 현지언론 화면, 거점 선택 시 상단 빅넘버.
- **기준 통화**: 달러(USD).
- **환율 소스**: open.er-api.com (무료·키불필요·일1회) — 11개국 통화 전부 커버.
- **지수 소스**: yfinance(야후), 실패 시 해당 카드 생략.
- **국가별**: GB=GBP+FTSE100 · **US=환율없음, 지수 2개(S&P500 ^GSPC + 나스닥 ^IXIC)** · HK=HKD+항셍 · CN=CNY+상해종합 · JP=JPY+닛케이225 · SG=SGD+STI · IN=INR+Nifty50 · **VN=VND+VNM ETF(대체)** · ID=IDR+자카르타종합 · **MM=환율만 · KH=환율만**.
- **표시**: 전일 대비 등락(값·%·▲▼), 상승 녹/하락 적.
- **주의**: MMK는 공식환율(시장환율과 괴리) / KHR·HKD 페그(거의 고정).
- **신규 모듈**: `indicators.py`, `main.py indicators`, `indicators` 테이블(일별 스냅샷).

## ② KB 미진출국 카테고리 — 상세는 design_미진출국.md

- **구조**: 최상위 [진출국] / [KB 미진출국]. 진출국은 국가별 카테고리 유지, 미진출국은 **국가 구분 없이 통합 피드**.
- **정렬**: **중요도(ai_score)순**.
- **기사 카드**: **국가 라벨·국기 표시** (국가 네비게이션은 없음). 주제 필터(금융/디지털/ESG/리스크) 유지.
- **처리**: 미진출은 Google News 국가 쿼리 경량 수집, AI 요약·topics까지만(KB시사점·국가브리핑 생략).
- **대상**: 한국계 은행 진출·KB 미진출 **14개국** — ⚠️ **잠정, 변경 가능**. (필리핀·태국·말레이시아·방글라데시·폴란드·독일·프랑스·카자흐스탄·우즈베키스탄·UAE·브라질·멕시코·호주·캐나다)

## ③ 오늘의 글로벌 핵심 3줄

- **위치**: 글로벌 동향(brief) 최상단.
- **내용**: 그날 11개국 ACTIVE 기사를 가로질러 AI가 종합한 핵심 3항목. 각 항목 = 카테고리 태그 + 건조한 헤드라인 + 거점 영향 1줄.
- **생성**: export 직전 LLM 1콜(하루 1회). `brief.json`의 `daily_highlights`.

## ④ 국가별 오늘의 이슈

- **위치**: brief, ③ 바로 아래.
- **내용**: **동적 top-5 국가**(⑤와 공유), 각 국가 = "국가명 – 이슈1 · 이슈2 · 이슈3" (짧은 키워드형 문구 2~3개).
- **소스**: `country_briefings.issues`의 title 재활용(거의 무비용).
- 예: `미국 – 캐나다 관세협상 결렬 · 무역전쟁 격화 · 연준 인플레 재검토`

## ⑤ 시장 무드 배지

- **위치**: brief, 국가별 섹션(④와 한 세트, **같은 top-5 공유**).
- **선정**: **동적 (B)** — 그날 이슈 강도(ai_score·기사수) top-5. 배지 풀 = 진출국 11 + 글로벌 블록(美·中·歐·日). 미진출국은 풀에서 제외.
- **배지 = 국기 + 대표 키워드 + 날씨 아이콘 + 추세 화살표 + 컬러 링**.
- **무드 5단계**: ☀️맑음(안정·호조) → ⛅ → ☁️흐림(주의) → 🌧️비(리스크) → 🌀태풍(위기). 계산 = 지표 방향 + 리스크 토픽 밀도 + ai_score. (프로토타입 온도계 공식 재활용)
- **하단**: "최근 N건 기준 · 갱신 시각" (근거 표기).
- 근거: 확정안 "아이콘 기반 시각화" 부활 — 재미요소가 아닌 **신호**로(아이콘+키워드+화살표로 근거 확보).

## Brief 첫 화면 최종 구성 (3층)

```
1. 오늘의 글로벌 핵심 3줄        (횡단 종합)
2. 국가별 오늘의 이슈 (top-5)    (국가축 텍스트)
3. 시장 무드 배지 (같은 top-5)   (아이콘 요약)
   → 2·3은 같은 5개국 = 하나의 "국가별 섹션"
```
