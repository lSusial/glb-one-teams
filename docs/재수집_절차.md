# 재수집 절차 (맥북 런북)

> 목적: **개선된 필터 + 싱가포르(SG)·홍콩(HK) 반영**한 최신 데이터로 갱신하고, 관리자 페이지·`countries.json`을 다시 생성한다.
> 실행 위치: **맥북** (Oracle Cloud 서버 IP는 Google News RSS 503 차단 → 수집은 맥북에서, 이후 서버 동기화)
> 배경: 현재 `data/news.db`는 2026-06-22 스냅샷이라 **구 필터 판정**이고 **HK/SG 기사 0건**. 아래 절차로 최신화.

## 0. 전제

```bash
cd ~/Documents/Claude/Projects/glb-one-teams   # 실제 경로
source .venv/bin/activate                        # 없으면: python -m venv .venv && .venv/bin/pip install -r requirements.txt
git pull                                          # 개선 필터(keyword_filter.py)·main.py 최신 반영
```

- 수집·필터·관리자 페이지는 **API 키 불필요**. (AI 단계만 `ANTHROPIC_API_KEY` 필요 — 이번 재수집엔 안 씀)

## 1. 소스 동기화 (HK/SG 포함 확인)

```bash
python main.py init          # sources.yaml → DB 동기화 (11개 거점·88소스·106피드)
```

기존 DB 유지하며 소스만 갱신(멱등). 출력의 `sources=88 feeds=106` 확인.

## 2. 수집 → 필터 → 중복 (개선 필터 적용)

```bash
python main.py run           # fetch → filter → dedup (신규 기사 수집·개선 필터로 판정)
```

> 서버에서 직접 하지 말 것(503). 반드시 맥북.

## 3. 기존 기사까지 개선 필터 재적용 (재측정용)

```bash
python main.py filter --refilter   # 전체 기사 재채점 (구 판정 → 개선 필터 판정)
python main.py dedup --recheck     # 중복 재탐지 (선택)
```

> 40,594건 재채점은 수십 초~1분가량. 이 단계까지 해야 구 스냅샷 기사도 개선 필터 기준으로 통일됨.

## 4. 확인

```bash
python main.py report        # data/availability_report.md — 매체별 수집·통과
python main.py list --limit 20
```

확인 포인트:
- **HK·SG 기사 > 0** (이전엔 0건)
- 통과율/노이즈가 개선 필터 기준으로 반영됐는지 (스포츠·정치성 감소, 거시·에너지·실적 유지)

## 5. UI/관리자 데이터 재생성

```bash
python main.py admin              # data/export/admin.html (관리자 페이지)
python main.py export --passed    # data/export/countries.json (Phase 1, AI 없이)
open data/export/admin.html       # 브라우저로 열람
```

## 6. 서버 동기화

```bash
./sync_to_server.sh               # DB만 전송
#  또는 수집까지 한 번에:
./sync_to_server.sh --collect
```

(서버 접속 정보·경로는 `CLAUDE.md` 참조)

- **AI 단계**(`prefilter`/`rank`/`brief`): Phase 2. `ai_score` 스케일 1~5(구 DB) → 코드 0~100(임계 60) 정리 후 실행. 지금 `export`(옵션 없이 ACTIVE)는 0건이 정상 → **`export --passed`** 사용.
- OFFICIAL 당국 피드 활성화, 자회사 IR, 거시지표 빅넘버 — 비-뉴스 소스라 보류(`PLAN.md` 이번 진행 범위).

## 문제 해결

| 증상 | 조치 |
|---|---|
| `ModuleNotFoundError` | `.venv` 활성화 / `pip install -r requirements.txt` |
| 피드 다수 503·빈 응답 | 서버에서 실행 중일 가능성 → 맥북에서 실행 |
| `export`가 0건 | 정상(ACTIVE는 AI 점수 필요). `export --passed` 사용 |
| RTHK 피드 오류 | 알려진 이슈(피드 자체 XML 오류), 무시 |
