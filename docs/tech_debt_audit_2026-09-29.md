# 기술부채·구조 점검 (2026-09-29)

운영 데이터 품질을 유지하면서 변경 사고를 줄이는 관점으로 소스, SQLite 스키마,
테스트, 정적 검사를 점검했다. 우선순위 점수는 `(영향도 + 장애위험) × (6 - 작업량)`이며
각 항목은 1~5점이다.

## 구조상 주의점

- `export_json.py`는 약 1,450줄이며 화면 JSON 계약과 HTML 주입을 함께 담당한다. 한 번에
  옮기면 배포 산출물이 조용히 달라질 위험이 커서, payload별 스냅샷 검증을 먼저 만든 뒤
  함수 단위로 분리하는 편이 안전하다.
- 국가명이 `kb_network.py`, `config.py`, `export_json.py`, 각 HTML에 중복되어 있다. 새 국가
  추가 때 누락되기 쉬우므로 6번 작업 전까지는 `CLAUDE.md` 체크리스트를 따라야 한다.
- 국가 탭 0건은 현재 전일+당일과 55점 기준을 정직하게 적용한 결과다. 코드 폴백으로
  저품질 기사를 채우기 전에 TH·LA 표본 검수와 거점별 적격 기준 결정이 필요하다.
- 빈 국가를 채우기 위해 45~54점 기사를 노출하면 일부는 한국어 요약이 없어 추가 번역
  비용이 생긴다. 자동화 비용 정책과 함께 결정해야 한다.
