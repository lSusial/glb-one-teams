> 배경: 2026-07-13 확정안의 "국가별 = KB 진출국 / 미진출국"을 이번에 구현 범위로 편입.

---

## 1. 확정된 결정 (2026-08-21)

| 항목 | 결정 |
|---|---|
| **네이밍** | **진출국 / KB 미진출국** ("관찰국" 안 씀) |
| **최상위 구조** | 국가 위에 [진출국] / [KB 미진출국] 구분 신설 |
| **진출국** | 그 아래 **국가별 카테고리 유지**(지금처럼 국가 선택 → 브리핑+피드) |
| **미진출국** | **국가로 나누지 않음** — 15개국 뉴스를 **한 덩어리 통합 피드**로 |
| **대상 선정 기준** | **한국계 은행은 진출했지만 KB는 없는 국가** 중 선별 |
| **대상 규모** | **14개국** (네덜란드 제외) — ⚠️ **잠정, 변경 가능** |

## 2. 구조 그림

```
현지언론 화면
├─ [진출국]              ← 기존 그대로, 위에 그룹 딱지만 추가
│   ├─ GB · US · HK · CN · JP · SG · IN · VN · MM · ID · KH (국가별 선택)
│   └─ 국가별: 브리핑 + 기사 피드
│
└─ [KB 미진출국]          ← 신규
    └─ 국가 구분 없이 하나의 통합 피드
        (기사별 국가 태그/국기는 표시하되, 국가별 네비게이션은 없음)
        (주제 필터 금융/디지털/ESG/리스크는 그대로 적용 가능)
```

- **진출국**은 축 A에 `presence: 진출` 딱지가 붙을 뿐, 아래 국가 구조·처리 방식 변화 없음.
- **미진출국**은 15개국을 `presence: 미진출`로 묶어 **국가 축을 접고**, 통합 피드 하나로. 국가별 브리핑 생성 안 함(피드만).

## 3. 처리 깊이 — 진출국 깊게 / 미진출국 넓게

| 구분 | 진출국 (11개) | KB 미진출국 (14개) |
|---|---|---|
| 수집 | 큐레이션 로컬 매체(sources.yaml) | **Google News 국가·언어 쿼리**(개별 매체 큐레이션 안 함) |
| AI | full (ai_score·요약·topics·KB시사점) | 경량 (ai_score·요약·topics) |
| KB 시사점 | 거점 맥락 주입 | **생략**(거점 없음) |
| 대상 | 11개국 | **14개국** |
| 국가 브리핑 | daily/weekly | **없음** (통합 피드만) |
| UI | 국가별 브리핑+피드 | 통합 피드(주제 필터 적용) |

> 미진출국은 "국가별 심층"이 아니라 "한국계 은행이 있는 시장의 소식을 훑는" 성격 → 통합 피드 + 경량 처리로 비용·운영 부담을 최소화.

## 5. 구현 변경점 (개요)

- **국가 메타**: `presence: 진출|미진출` 필드 + 미진출 15개국을 Google News 쿼리 엔트리로 등록.
- **kb_network.py**: 미진출국은 거점 없음 → 시사점 스킵 경로.
- **AI 레이어**: 미진출이면 KB시사점·국가브리핑 단계 스킵(경량).
- **export_json.py**: `countries.json`에 `presence` 반영 + 미진출은 국가 병합 통합 피드로 export.
- **web/countries.html**: 상단 [진출국]/[KB 미진출국] 구분. 미진출은 국가 네비 없이 통합 피드(주제 필터 유지), 기사 카드에 국가 태그.
