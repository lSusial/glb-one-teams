## [0] 진출국 태국·라오스 추가
```
[작업] 진출국에 태국(TH)·라오스(LA) 추가
- config의 진출국 목록에 TH·LA 추가. 태국은 미진출 14에서 제거(미진출→진출 이동), 라오스 신규.
- 결과: 진출 13 / 미진출 13. sources.yaml에 TH·LA 수집 엔트리(가능하면 큐레이션, 최소 Google News 쿼리).
- 지표: TH=지수(SET)·환율(THB), LA=지수없음·환율(LAK)만(MM·KH와 동일 취급).
- kb_network.py 등 거점 정의에도 반영. 검증: 두 나라가 진출국으로 수집·표시, 미진출에서 사라짐 / py_compile.
작업 전 가정 먼저, 계획 요약 후 진행.
```

## [1] 모니터링 3분류 + 브리프 Top10
```
[작업] 모니터링 카테고리 재편 + 브리프 Top10
## A. 모니터링(topics) 하위: 규제/거래·투자/사건사고 (이벤트축, 멀티라벨)
 · REG 규제(감독·정책·제재·인허가·과징금·컴플라이언스) · DEAL 거래·투자(투자·M&A·지분·매각·펀딩·IPO·제휴·진출) · INCIDENT 사건사고(사고·부정·횡령·사기·파산·부실·해킹·유출·소송)
 · taxonomy.yaml에 이벤트축(seeds) 정의, AI가 event_type 부여. 기존 topics(현지언론 필터)는 유지·별도.
 · topics.json 카테고리·필터를 event_type로, 모니터링 탭 3개 교체, 빈 탭 숨김.
## B. 브리프 핵심 = Top 10 전체국가 (daily_highlights 개수 config로 10, 이미 10이면 확인만).
검증: 모니터링 3탭·event_type 분류·멀티라벨, 현지언론 회귀 없음, 브리프 10건 / py_compile.
작업 전 가정 먼저, 계획 요약 후 진행.
```

## [2] 미진출 ai_score + 정렬 + 근접중복
```
[작업] 미진출 AI 점수화 + 통합 피드 중요도순 + 근접중복 제거
- 미진출도 llm_ranker 경량으로 ai_score+summary_ko+topics 부여(KB시사점·국가브리핑 생략). Haiku+Batches, 증분.
- non_presence 피드 = ai_score desc(동점 최신).
- 같은 국가 내 제목 토큰 Jaccard≥0.5(config) 동일사건 → 대표 1건(최고 ai_score) + related_count, UI "관련 N건".
검증: 미진출 ai_score 채워짐/피드 정렬/필리핀 금리 4건→대표1+related_count=3/과합침 없음/회귀 없음.
작업 전 가정 먼저, 계획 요약 후 진행.
```

## [3] 브리프 메인 개편(지도) + 기사 공용 모달
```
[작업] 브리프 메인 개편(지도형) + 기사 공용 모달 — 프로토타입 베이스
## 참조: docs/mockups/브리프_구성_프로토타입.html, data/export/pulse·countries·topics.json
## 원칙: 기존 web/*.html 유지, 새 파일 web/brief_v2.html(fetch 상대경로). 색·레이아웃 최종디자인은 추후. 최소 코드.
## A. 브리프
 1) 프로토타입 구조 채택 2) 글로벌 온도 섹션 제거 3) 국가 신호 보드 제거
 4) 지도형 "국가별 상황" 신설: country_signals 진출국을 세계지도 신호색(안정녹/주의주황/경계적) 마킹,
    클릭/호버 팝오버(keyword+지수 등락%+환율USD, 지수없는 MM·KH·LA는 환율만). 인라인 SVG 또는 경량 지도 라이브러리.
 5) 오늘의 글로벌 핵심 Top10 유지.
## B. 기사 공용 모달(1개, 중복금지): 제목(t)·카테고리(c)·출처·날짜(src·d)·KB시사점(k)·요약(expanded_summary 있으면, 없으면 q+관련종합)·관련링크(rl/source_links, 없으면 u).
    적용: 브리프 Top10 + 현지언론(진출·미진출 카드) + 모니터링(클러스터 기사).
검증: 지도 신호색·팝오버, 온도·보드 사라짐, Top10 유지, 3화면 동일 모달, 필드 없어도 안깨짐, fetch 동작/회귀 없음.
작업 전 지도 방식(SVG vs 라이브러리)·진출국 코드·좌표 매핑 3~5줄 제시 후 착수.
```

## [4] 국가 지표 확장(정책금리+국채금리+스파크라인)
```
[작업] 국가별 금융지표 확장 — 정책금리 + 국채금리 + 추세 스파크라인
- 정책금리(전국): config 소형표 POLICY_RATES[cc]={value,as_of} 시드·유지. indicators kind='policy_rate'.
- 10년물 국채금리(가능국만): yfinance/stooq 시도, 없으면 생략. kind='bond10y', 등락(bp).
- 스파크라인(새 소스 없음): 일별 indicators 스냅샷 최근 7영업일 → countries.json indicators에 spark:[...] 추가, 부족시 생략.
- UI(현지언론 지표 스트립): 정책금리 1줄 추가(=3개 기준), 국채금리 있는국만, 환율·지수 옆 미니 스파크라인. 밀도 조절.
검증: policy_rate 전국·bond10y 일부·spark 가능분 존재, config만 고쳐 값변경, 없는국 생략/회귀 없음.
작업 전 정책금리 시드값·국채 커버국 목록 먼저 제시 후 착수.
```

## [5] 기사 긴 요약(expanded_summary)
```
[작업] 기사 긴 요약 생성 — 모달용 10~20줄
- 새 필드 expanded_summary(짧은 q는 유지). 10~20줄(4~6문단/문단+bullet).
- 구성: ①핵심사실 ②배경·맥락 ③수치 ④파급·전망 (KB시사점은 k 별도).
- 다출처 종합(관련 클러스터 함께 입력, 단일복제 X), 신문 데스크 톤, AI티 배제, 환각 금지, 출처 유지.
- 비용: 노출 기사에만(브리프 Top10 + ACTIVE 현지언론/모니터링), 증분, Haiku+Batches.
- 모달은 expanded_summary 있으면 사용, 없으면 q 폴백.
검증: 노출기사 10~20줄(표본5)/다출처·중복없음/비노출 미생성/모달 채워짐/py_compile.
```
