## 3. 현지언론 — 구성요소 & 데이터

| 구성요소 | 내용 | 데이터 소스 | 상태 |
|---|---|---|---|
| 진출국 (13) | 국가 선택 → 일일 브리핑 + 기사 피드 | countries.json `countries` | ✅/🆕 |
| 기사 카드 | 제목·요약·KB시사점·원문·주제필터(금융/디지털/ESG/리스크) | countries.json | ✅ |
| 지표 스트립 | 환율·지수(USD) | countries.json `indicators` | ✅ |
| 미진출국 (13) | 국가 구분 없이 통합 피드, 중요도순, 중복제거, 국기·국가라벨 | countries.json `non_presence` | 🔧(ai_score·정렬·중복) |
| 한국계 금융기관 | 신한·하나 등 언급 기사 태그/모아보기 | `korean_fi` 태그 | 🆕 |

> **진출국(확정): 13** = 기존 11 + **태국·라오스 추가**. 태국은 미진출→진출 이동, 라오스 신규.
>   라오스(LA)는 프론티어라 지수 없음 → 환율(LAK)만, MM·KH와 동일 취급. 태국(TH)은 지수(SET)·환율(THB) 있음.
> **미진출국(확정): 13** = 태국 제외. ⚠️ 확신도 '중' 5개국(말레이시아·프랑스·브라질·멕시코·호주·캐나다) **사업그룹 검증** 필요.

## 6. 확정 결정 요약 (이번 세션+회의)
- **브리프 생성 = 매일 05:00 KST, 전일+당일 창** (일일). → 정기 자동화 필요.
- **메인 = 뉴스 Top 10** 최상단. 클릭 → **모달**(요약 10~20줄 + 기사 링크).
- **진출국 13** (기존 11 + 태국·라오스), **미진출 13** (태국 이동).
- 모니터링 = **규제/거래·투자/사건사고** 3분류(이벤트축, 멀티라벨).
- 미진출 피드 = **ai_score 중요도순** + 근접중복 제거(관련 N건).
- 지표 = **USD 기준 환율+지수**, 미·MM·KH·(라오스) 특수표기.
- 국가 신호 = 3단계(안정/주의/경계), 무드(날씨) 대체.
- 키맨 **제거**. 요약 = **3개+ 언론사 종합 + AI티 제거**.
- 주간 리포트 **유지**.
